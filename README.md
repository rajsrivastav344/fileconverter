# 📄 File Converter (Flask)

A simple and efficient **File Converter Web Application** built using **Flask** that allows users to upload files and convert them into different formats through an easy web interface.

---

## 🚀 Features

* 📂 Upload files easily
* 🔄 Convert files into multiple formats
* ⚡ Fast processing using Flask backend
* 🖥️ Clean and simple UI
* 📥 Download converted files instantly

---

## 🧱 Tech Stack

* **Backend:** Flask (Python)
* **Frontend:** HTML, CSS, JavaScript
* **Server:** Flask Development Server

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/file-converter.git
cd file-converter
```

---

### 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

Activate environment:

**Windows**

```bash
venv\Scripts\activate
```

**Mac/Linux**

```bash
source venv/bin/activate
```

---

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 4️⃣ Run the Flask Application

```bash
python app.py
```

---

## ▶️ Usage

1. Open browser and visit:

```
http://127.0.0.1:5000
```

2. Upload a file.
3. Choose output format.
4. Click **Convert**.
5. Download the converted file.
